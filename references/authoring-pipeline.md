# Authoring Pipeline

```text
Truth + Reader Brief + Document Strategy
  → Human-first Authoring
  → Truth Lock structural check
  → UX Writing on routed compact roles
  → optional Voice Adaptation
  → Conservative Humanity on routed prose roles
  → Authored Content
  → Truth Lock validation
```

Workers are model-mediated instruction workers, not deterministic software
functions. Technical text bypasses generic humanization. Any Truth Lock failure
means `AUTHORING_CANDIDATE_REJECTED`; Truth is never repaired to fit prose.
