# Status Taxonomy

Keep internal ontology separate from reader wording. Use independent fields:
`epistemic_state` (`observed`, `source_backed`, `inferred`, `unknown`,
`not_found`), `closure_state` (`verified`, `partial`, `open`, `blocked`,
`not_applicable`), and `risk` (`low`, `medium`, `high`, `critical`,
`unspecified`). Human labels must never strengthen these values.
