# Omega HTML v2 Candidate

Omega HTML v2 is a parallel candidate.
It does not replace the installed omega-html v1.
Its objective is to become a general-purpose human artifact publishing system.
Promotion requires semantic, human, visual, and technical gates.

Quality gap: `OMEGA_HTML_HUMAN_FACING_ARTIFACT_QUALITY_GAP`

Primary principle: **More human. More beautiful. Never less true.**

This Gate 1 package is foundation-only. Rendering, authoring workers, external
skills, and promotion are intentionally not implemented.
